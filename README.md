# ATLAS · El Archivo de las Cuatro Voces 🔎

**Una aventura detectivesca para aprender idiomas.** Investiga casos, encuentra pistas y aprende por comparación entre inglés, francés, alemán, ruso y japonés. Toda la navegación está pensada en español.

**Estado:** demostración experimental, con capítulos y ejercicios ampliables. Los materiales de ejemplo no se consideran traducciones ni audios certificados.

## Para quienes quieran entrar en los detalles

Se conserva íntegramente la [guía técnica anterior, con el recorrido de versiones 0.1–0.8](docs/history/README-tecnico-2026-10-12.md). El código de pruebas, el manifiesto de publicación y los procedimientos de despliegue permanecen en sus carpetas originales.

**Importante:** cambiar de GitHub Pages a Cloudflare no lleva consigo los datos guardados en el navegador. Usa las opciones de exportar e importar progreso antes de cambiar la URL habitual.
