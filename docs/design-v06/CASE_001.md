# Caso 001 revisado — La llave equivocada

**Objetivo:** cerrar un misterio justo y utilizar vocabulario en contexto real. No sustituye el caso publicado hasta pasar QA.

## Pistas visibles
A. En un libro abierto se encuentra una hoja con **ROOM 12** y una anotación equivalente en español. Registrar origen, página y hora aproximada. Relación educativa: book / le livre / das Buch / книга / 本（ほん）.
B. En el escritorio hay una llave cuyo llavero dice **21**. Un zoom muestra una marca de adhesivo debajo de la etiqueta reciente. Relación: key / la clé / der Schlüssel / ключ / 鍵（かぎ）.
C. Un **registro de asignación** (no confundir con una carta) tiene 12 tachado y 21 manuscrito. No atribuir autoría a alguien únicamente porque la tinta parece igual.
D. En el tablero se conserva **una carta** con una fecha y referencia cruzada; permite practicar letter / la lettre / der Brief / письмо / 手紙.
E. Junto a la ventana, un mapa opcional. Map / la carte / die Karte / карта / 地図. El mapa es un objeto realmente visible.
Cada prueba tiene icono, zoom, texto legible, fuente diegética y entrada en el cuaderno.

## Rutas
**Observador:** encuentra pegamento antes de abrir registro; puede inferir sustitución material.
**Entrevistador:** pregunta a Nora cuándo llegó la llave; obtiene cronología antes de comparar.
**Descifrador:** recibe dos versiones de una anotación con apoyo de glosa, nunca un examen que no haya sido enseñado.
Todas las rutas permiten obtener A + B + C y una solución coherente.

## Mecánicas
Inspeccionar → ampliar documento → anotar hecho → conectar A/B/C en tablero → reconocer una palabra → escribirla sin apoyo (o aceptar ayuda y registrar que NO demuestra dominio) → presentar hipótesis al cierre.

**Conclusión probada:** dos registros discrepan, la etiqueta fue sustituida y la asignación fue corregida. **No probado:** quién, por qué, si el cambio es malicioso. La pregunta final exige señalar un límite de lo que sabemos.

**Giro final:** aparece un sobre con el mismo sello que la invitación, vinculado a la etiqueta sustituida. Nora: «Tenemos una relación. Todavía no tenemos un culpable».

## Integración educativa
Una mecánica no consiste en pulsar «book» para abrir una puerta: consiste en leer un documento que incluye esa palabra y usarla para seleccionar una prueba relevante. Nadie aprende gramática por resolver el misterio solo. Enseñar artículos alemanes antes de evaluarlos; ruso y japonés reciben alfabetización incremental y teclados compatibles.
